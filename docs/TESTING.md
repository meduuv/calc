# Testing Checklist

Before merging calculator changes, verify:

- Basic addition, subtraction, multiplication, and division
- Decimal input
- Percentage behavior
- Backspace and clear controls
- Calculation history
- Keyboard shortcuts
- Repeated calculations
- Division by zero handling
- Layout at desktop and narrow viewport sizes

For browser changes, test in at least one current Chromium-based browser and one additional modern browser when available.
