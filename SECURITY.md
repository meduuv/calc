# Security Policy

## Supported versions

The latest version on the `main` branch is the supported version.

## Reporting a vulnerability

If you find a security issue, avoid posting sensitive details publicly. Report it privately through the contact method listed on the project owner's GitHub profile.

Please include:

- A clear description of the issue
- Steps to reproduce it
- Expected and actual behavior
- Any relevant browser or environment details

Do not include passwords, tokens, private keys, or other secrets in a report.
