# Contributing to Calc

Thanks for contributing to Calc.

## Development

Calc is intentionally lightweight and uses plain HTML, CSS, and JavaScript. No build system or package installation is required.

1. Fork the repository or create a feature branch.
2. Make a focused change.
3. Test the calculator in a modern browser.
4. Check keyboard input, arithmetic behavior, and history when relevant.
5. Open a pull request with a clear description of the change.

## Pull requests

Keep pull requests focused and avoid unrelated formatting changes. Include reproduction steps for bug fixes and a short testing note for behavior changes.

## Code style

Prefer readable, small functions and browser-native APIs. Avoid adding dependencies unless they provide clear value for the project.

## Reporting bugs

Include the browser, steps to reproduce, expected behavior, and actual behavior. Screenshots or a minimal reproduction are useful for UI issues.
